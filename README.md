# HypnosyncWikiTemplate
HYPNOSYNC(ヒプノシンク)Wikiのテンプレート集

> [!NOTE]
> テンプレートを使用する前にお読みください。

## 楽曲テンプレート

> [!IMPORTANT]
> ページを作成する際、ページ名を`一覧/収録楽曲/(楽曲名)`にしてページを作成してください。  
> 以下の文字は全角文字で代用してください。
> - `"` → `”`
> - `#` → `＃`
> - `&` → `＆`
> - `<` → `＜`
> - `>` → `＞`
> - `:` → `：`
> - `/` → `／`

### 1. タイトル  
1-1. `(楽曲名)`に楽曲名を記入する。

### 2. 概要  
2-1. 漢字やアルファベットまたは特殊な読み方があれば、適宜に振り仮名を記入する。 
- 漢字への振り仮名は**平仮名**で記入する。
- アルファベットへの振り仮名は**カタカナ**で記入する。
- 該当箇所が複数あれば複数記入する。
```
例1: 同じ星空の下で → &ruby(おな){同};じ&ruby(ほしぞら){星空};の&ruby(した){下};で
例2: GOODTEK → &ruby(グッドテック){GOODTEK};
例3: INFiNiTE ENERZY -Overdoze- → &ruby(インフィニティ){INFiNiTE}; &ruby(エナジー){ENERZY}; -&ruby(オーバードーズ){Overdoze};-
```

2-2. `(コンポーザー名)`にコンポーザー名を記入する。  
2-3. `(BPM)`にBPMを記入する。  
2-4. `(拍子)`に拍子を記入する。  
2-5. `(演奏時間)`に演奏時間を`(分):(秒).(ミリ秒)`の形式で記入する。  
2-6. `(キャラクター名)`にキャラクター名を`[[(キャラクター名)>一覧/キャラクター/(キャラクター名)]]`の形式で記入する。  
2-7. `(曲ID)`に曲IDを記入する。  
2-8. `(解禁条件)`に解禁条件を記入する。  
2-9. `(追加ver.)`に楽曲が追加されたバージョンを記入する。

### 3. 難易度表  
3-1. `(楽曲名)`に楽曲名を記入する。  
3-2. 難易度ごとにレベル・総ノーツ数を記入する。

### 4. 楽曲詳細  
4-1. 該当する楽曲の説明を記入する。
- このセクションでは、他に収録されている音楽ゲームについては記入しない。(`(音楽ゲーム)に書き下ろされた楽曲`の形式は除く。)

### 5. 通称  
5-1. よく呼ばれている呼び名を番号なしリスト形式で記入する。

### 6. 他に収録されている音楽ゲーム  
6-1. HYPNOSYNC以外にも収録されている音楽ゲームを番号なしリスト形式で記入する。  
6-2. 該当するWikiのページがあれば、`[[(音楽ゲーム)>(その楽曲のWikiのページのURL)]]`の形式で記入する。  
6-3. 通常の音源とは異なる場合、隣に括弧`()`で補足する。
```
例: 
- Bleap
- [[Liminality>https://wikiwiki.jp/liminality/Ops_Limone%20-FINAL%20EX-]] (FINAL EX)
- [[Muse Dash>https://wikiwiki.jp/musedash/Ops.Limone]]
- [[OverEcho>https://wikiwiki.jp/overecho/Ops%EF%BC%9ALimone]]
- RoBeats!
- [[TAKUMI&#179;>https://wikiwiki.jp/takumi_game/Ops%20Limone%20-FINAL%20EX-]] (FINAL EX)
- [[vivid/stasis>https://wikiwiki.jp/vividstasis/Ops%20Limone]]
- [[シノビスラッシュ>https://wikiwiki.jp/shinobislash/Ops%EF%BC%9ALimone%20-FINAL%20EX-]] (FINAL EX)
```

### 7. 変更履歴
7-1. HYPNOSYNCのアップデートで変更された要素を番号なしリスト形式で記入する。
```
例:
- HSYNC.2026.10.30.00
-- 難易度
--- NORMAL: 6 → 4
--- TRANCE: 13 → 11
-- タイトル
--- 「Ops Limone」→「Ops:Limone」
-- コンポーザー名
--- 「Artermis」→「Altermis」
- HSYNC.2026.10.30.00
```

### 8. 公式音源  
8-1. HYPNOSYNC公式またはコンポーザー本人が公開している公式音源があれば、コメントアウトを外す。  
8-2. YouTubeの公式音源があれば、コメントアウトを外し、YouTubeのURL`https://www.youtube.com/watch?v=(ビデオID)`から、`(ビデオID)`を記入する。[参考](https://wikiwiki.jp/sample/youtube)  
8-3. SoundCloudの公式音源があれば、コメントアウトを外し、トラックIDを記入する。[参考](https://wikiwiki.jp/sample/SoundCloud)

## 譜面テンプレート

> [!IMPORTANT]
> ページを作成する際、ページ名を`一覧/収録楽曲/(楽曲名)/(難易度)`にしてページを作成してください。  
> 以下の文字は全角文字で代用してください。
> - `"` → `”`
> - `#` → `＃`
> - `&` → `＆`
> - `<` → `＜`
> - `>` → `＞`
> - `:` → `：`
> - `/` → `／`

### 1. タイトル  
   1-1. `(楽曲名)`に楽曲名を記入する。  
   1-2. `(難易度)`に難易度を記入する。(BASIC,NORMAL,TRANCE)
   
### 2. DAZE条件(難易度がBASIC,NORMALのときはスキップ)  
   2-1. DAZE条件のセクション部分のコメントアウトを外す。  
   2-2. `条件`の列に、色に合った条件をそのまま記入する。  (条件がない場合、半角のハイフン(-)にする。)
   2-3. `備考`の列に、その条件の詳細を記入する。(一文が長くならないように)
   
### 3. ノーツ表  
   3-1. ノーツの表に、ノーツの種類とレーンに合ったノーツの個数を記入する。  
   3-2. ノーツのそれぞれの合計を記入する。

### 4. 難所
   4-1. 譜面で難しい箇所を番号なしリスト形式で記入する。

### 5. 攻略・コツ  
   5-1. 難所の攻略や対策を番号なしリスト形式で記入する。
   
### 6. 譜面画像
   6-1. 譜面画像があればコメントアウトを外す。  
   6-2. `(楽曲ID)`に楽曲IDを記入する。  
   6-3. `(難易度)`に難易度を記入する。(BASIC,NORMAL,TRANCE)

### 7. 譜面動画  
   7-1. [HYPNOSYNC(ヒプノシンク)Wiki YouTubeチャンネル](https://www.youtube.com/@HYPNOSYNCWiki)から、該当する動画があればコメントアウトを外す。  
   7-2. YouTubeのURL`https://www.youtube.com/watch?v=(ビデオID)`から、`(ビデオID)`を記入する。[参考](https://wikiwiki.jp/sample/youtube)  

### 8. コメント  
   8-1. [HYPNOSYNC(ヒプノシンク)Wiki 掲示板](https://z.wikiwiki.jp/hypnosync/tag/Wiki)から、該当するトピックがあればコメントアウトを外す。  
   8-2. zawazawaのURL`https://z.wikiwiki.jp/hypnosync/topic/(トピックID)`から`(トピックID)`を記入する。

## キャラクターテンプレート

> [!IMPORTANT]
> ページを作成する際、ページ名を`一覧/キャラクター/(キャラクター名)`にしてページを作成してください。  
> 以下の文字は全角文字で代用してください。
> - `"` → `”`
> - `#` → `＃`
> - `&` → `＆`
> - `<` → `＜`
> - `>` → `＞`
> - `:` → `：`
> - `/` → `／`

### 1. 基本情報
1-1. `(キャラクター名)`にキャラクター名を記入する。
1-2. `(読み方)`にキャラクターの読み方を**カタカナ**で記入する。
1-3. `(タイプ)`にタイプ(`黄`, `青`, `赤`, `灰`, `?`)を記入する。&br;タイプは、キャラクター名の左側にあるマークの色とします。
1-4. `(レアリティ)`に`★×(「★」の数)`と記入する。
1-5. `(役割)`に、そのキャラクターの役割を記入する。
1-6. `(身長)`に、そのキャラクターの身長を記入する。
1-7. `(出身地)`に、そのキャラクターの出身地を記入する。
1-8. `(趣味)`に、そのキャラクターの趣味を記入する。
1-9. `(スキル)`に、そのキャラクターのスキル名を記入する。
1-10. `(担当楽曲)`に、そのキャラクターの担当楽曲を記入する。

### 2. キャラクター説明
2-1. `(キャラクターの説明)`に、そのキャラクターの説明を記入する。  
2-2. 行が複数ある場合、行ごとに先頭に`> `を付け加える。

### 3. セリフ
3-1. `(従業員時のセリフ)`に、そのキャラクターの従業員時のセリフを記入する。  
3-2. `(パートナー選択時のセリフ)`に、そのキャラクターのパートナー選択時のセリフを記入する。  
3-3. `(パートナー決定時のセリフ)`に、そのキャラクターのパートナー決定時のセリフを記入する。  
3-4. `(休憩室入室時のセリフ(パターン1))`に、そのキャラクターの休憩室入室時のセリフの1つ目のパターンを記入する。  
3-5. `(休憩室入室時のセリフ(パターン2))`に、そのキャラクターの休憩室入室時のセリフの2つ目のパターンを記入する。  
3-6. `(話(パターン1))`に、そのキャラクターの「話」ボタンを押した時のセリフの1つ目のパターンを記入する。  
3-7. `(話(パターン2))`に、そのキャラクターの「話」ボタンを押した時のセリフの2つ目のパターンを記入する。  
3-8. `(話(パターン3))`に、そのキャラクターの「話」ボタンを押した時のセリフの3つ目のパターンを記入する。  
3-9. `(タッチ(パターン1))`に、そのキャラクターの「タッチ」モードでキャラクターに触れた時の1つ目のパターンを記入する。  
3-10. `(タッチ(パターン2))`に、そのキャラクターの「タッチ」モードでキャラクターに触れた時の2つ目のパターンを記入する。  
3-11. `(タッチ(パターン3))`に、そのキャラクターの「タッチ」モードでキャラクターに触れた時の3つ目のパターンを記入する。  
3-12. `(レベルアップ時のセリフ)`に、そのキャラクターのレベルアップ時のセリフを記入する。  
3-13. `(おやつを与えた時のセリフ(パターン1))`に、そのキャラクターのおやつを与えた時の1つ目のパターンのセリフを記入する。  
3-14. `(おやつを与えた時のセリフ(パターン2))`に、そのキャラクターのおやつを与えた時の2つ目のパターンのセリフを記入する。  
3-15. `(おやつを与えた時のセリフ(パターン3))`に、そのキャラクターのおやつを与えた時の3つ目のパターンのセリフを記入する。  
3-16. `(メインメニュー時のセリフ(パターン1))`に、そのキャラクターのメインメニュー時のセリフの1つ目のパターンのセリフを記入する。  
3-17. `(メインメニュー時のセリフ(パターン2))`に、そのキャラクターのメインメニュー時のセリフの2つ目のパターンのセリフを記入する。  
3-18. `(メインメニュー時のセリフ(パターン3))`に、そのキャラクターのメインメニュー時のセリフの3つ目のパターンのセリフを記入する。
